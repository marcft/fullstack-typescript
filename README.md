# FullStack TypeScript Learning Repository

This repository contains projects and exercises where I learned TypeScript by building real and fullstack applications.

## Projects

### Course Info

A React application that displays information about various courses. It uses TypeScript for type safety and Vite for fast development.

### Patientor

A fullstack application for managing patient records. The backend is built with Node.js and TypeScript, while the frontend uses React and TypeScript.

### Ilari Flights

A React application for searching and booking flights. It uses TypeScript for type safety and Vite for fast development.

## Technologies Used

- TypeScript
- React
- Node.js
- Vite
- ESLint

## Setup Instructions

1. Clone the repository.
2. Navigate to the project directory.
3. Install dependencies using `npm install`.
4. Run the development server using `npm run dev`.

## Learning Outcomes

- Understanding of TypeScript basics and advanced features.
- Experience with fullstack development using TypeScript.
- Familiarity with modern frontend tools like React and Vite.
- Best practices for code quality using ESLint.
